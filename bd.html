12. Настройка полей email и phone (удаление UNIQUE, добавление обычных индексов)

Для реализации возможности повторной отправки формы с тем же email/телефоном (чтобы пользователь мог оформить несколько заказов) были сняты ограничения уникальности. Вместо них созданы обычные индексы для ускорения поиска.

  • ALTER TABLE auto_users DROP INDEX email; – удалён уникальный индекс email
  • ALTER TABLE auto_users DROP INDEX phone; – индекс phone не существовал (ошибка игнорируется)
  • ALTER TABLE auto_users ADD INDEX idx_email (email); – добавлен обычный индекс
  • ALTER TABLE auto_users ADD INDEX idx_phone (phone); – добавлен индекс для телефона
Скриншот 12 – Удаление UNIQUE и добавление обычных индексов
